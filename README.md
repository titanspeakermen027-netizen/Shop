# ShopBot Phase 83
## الإعداد من داخل Discord
لا تحتاج لتعديل `config.json` يدوياً. بعد تشغيل البوت استعمل:
- `/settings shop-channel`
- `/settings orders-category`
- `/settings staff-role`
- `/settings work-threads-channel`
- `/settings reports-channel`
- `/settings offers-channel`
- `/settings seller-role`
- `/settings verified-seller-role`
- `/settings show`

## Marketplace
- `/marketplace channel-add`
- `/marketplace channel-remove`
- `/marketplace channel-list`
- `/marketplace mention` لاختيار Role أو @here أو @everyone أو بدون منشن
- `/marketplace mention-show`

الـ `.env` فقط يحتاج DISCORD_TOKEN.
